# Kristoffer Carlin Website

Norwegian-first, English-supported website for Kristoffer Carlin.

## Brand direction
Forest green, moss, ivory, warm ochre, golden yellow, terracotta and dark earth. Nordic, organic, grounded, sensual, energetic and human—not a generic spa template.

## Technology constraints
- GitHub for source
- Google Apps Script for backend
- Google Sheets for structured data
- Google Drive for photos and gallery media

Do not add Firebase, Cloud Run, or other backend services without explicit approval.

## Launch status
This repository is being built in stages. Booking capacity enforcement, server-side admin authentication, workshop management, photo uploads, newsletter consent/unsubscribe, booking notifications, and bilingual content must be implemented and tested before production launch. No fictional events or testimonials should be displayed.
